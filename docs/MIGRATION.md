# runyth-tables-of-sustenance-dnd5e-2024-1.0.1

## Migration from Tables of Sustenance 1.0.1

1. Back up the world.
2. Install core 1.1.0 and this companion before enabling the updated core in an existing D&D world.
3. Enable both modules.
4. Run Diagnostics.
5. Use Content Manager preview/update for previously imported foods.

Stable core `sourceId`, `effectId`, Tier 4 cooldown flags, Tier S permanent-benefit records and image overrides are preserved. Existing D&D Items remain system Documents; managed updates re-materialise their canonical core source through this adapter. User-edited managed content remains protected when the core preservation setting is enabled.

Legacy Tier S custom benefit records are recognised by the companion for migration compatibility.

## Patch update from companion 1.0.0 to 1.0.1

No data migration is required. Replace the companion module and reload the world. Existing primed-benefit flags, imported Items, Active Effects, cooldowns and permanent-benefit records retain their existing stable IDs.
