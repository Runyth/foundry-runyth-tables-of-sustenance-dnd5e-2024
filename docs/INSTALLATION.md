# runyth-tables-of-sustenance-dnd5e-2024-1.0.1

## Installation

1. Install `runyth-tables-of-sustenance` 1.1.0+.
2. Extract this module into `Data/modules/runyth-tables-of-sustenance-dnd5e-2024`.
3. Restart Foundry VTT.
4. In a D&D Fifth Edition world, enable both modules.
5. Run core Diagnostics. Adapter status should report `dnd5e-2024`.
6. Preview Content Manager updates before changing existing imported foods.
