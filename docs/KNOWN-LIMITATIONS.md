# runyth-tables-of-sustenance-dnd5e-2024-1.0.1

## Known Limitations

1. This release targets dnd5e 5.3.x on Foundry v13, not the unreleased/next-major 6.0.x code line.
2. Contextual legendary bonuses require explicit priming because narrative source inference is intentionally narrow.
3. Maximum-vitality Tier S benefits use a persistent Active Effect on the shared `system.attributes.hp.tempmax` field for Actor-schema breadth; the core permanent record remains authoritative.
4. Live Foundry acceptance must be performed in a licensed v13 client.
