# runyth-tables-of-sustenance-dnd5e-2024-1.0.1

## Runyth Tables of Sustenance - D&D 5e 2024

Complementary D&D 5e 2024 implementation for the system-neutral **Runyth Tables of Sustenance** core.

This module contains no duplicate cuisine catalogue. It consumes all 335 canonical core foods and supplies D&D Fifth Edition Item materialisation, serving storage, Active Effect mappings, contextual roll handling, rest recovery and D&D-specific diagnostics.

### Requirements

- Foundry VTT 13.347–13.351.
- D&D Fifth Edition 5.3.0–5.3.3; verified against 5.3.3.
- `runyth-tables-of-sustenance` 1.1.0 or newer.

D&D release source: https://github.com/foundryvtt/dnd5e/releases

### Coverage

| Content | Count |
|---|---:|
| Core foods materialised | 335 |
| Narrative-only foods | 180 |
| Foods with mechanical intents | 155 |
| Supported built-in intent kinds | 11 |

All 335 foods are implemented because ordinary food still requires a valid D&D Item representation for inventory quantity, weight, price, identification and servings even when it grants no effect.

Repository default branch: `master`.
